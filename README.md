# Biblioteca de Prompts

## Sobre o projeto

A Biblioteca de Prompts é um MVP (Produto Mínimo Viável) desenvolvido para facilitar o acesso e a utilização de comandos para ferramentas de Inteligência Artificial.

O sistema tem como público-alvo estudantes, profissionais e pessoas que estão começando a utilizar ferramentas de IA.

## Objetivo

Permitir que os usuários encontrem, visualizem, organizem e copiem prompts de forma simples e rápida.

## Funcionalidades previstas

- Pesquisa de prompts por palavra-chave.
- Visualização do conteúdo dos prompts.
- Organização por categorias.
- Cópia dos prompts para utilização em ferramentas de IA.

## Tecnologias previstas

- Python.
- Interface web com HTML, CSS e JavaScript.
- Banco de dados SQLite.
- Arquitetura monolítica em camadas.

## Status do projeto

Em fase inicial de desenvolvimento, com implementação e testes previstos nas próximas etapas da Experiência Prática III de Projeto de Software.
